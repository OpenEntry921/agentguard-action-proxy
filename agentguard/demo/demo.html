AgentGuard Execution Gate for AGAF Governance

AGAF defines governance evidence. AgentGuard does not decide what the organization should allow; it enforces the execution authority already defined by AGAF before anything can settle.

The AI Agent remains free to reason and propose financial actions, including incorrect ones. Execution authority is granted only when the request complies with organizational governance.

Settlement is always downstream of AgentGuard. When the execution request fails AGAF-derived governance checks, AgentGuard blocks the request and settlement never occurs.
