# AgentGuard Roadmap

## Strategic Direction

AgentGuard's roadmap is organized around the following structure:

```text
Context
↓
Harness
↓
Autonomy
```

AgentGuard is the Harness Layer for Autonomous AI. The roadmap therefore starts with strategic documentation, moves into context discovery, strengthens the runtime harness, and then expands into demonstrations, reputation, ontology, and knowledge graph capabilities.

## Phase 0 — Documentation & Positioning

- AgentGuard Positioning
- Context Engineering
- Harness Engineering
- Execution Integrity
- Behavior Pattern Taxonomy
- Policy Pattern Taxonomy

## Phase 1 — API Context Discovery MVP

- OpenAPI input
- Action / Resource extraction
- Risk Category mapping
- Policy Candidate generation
- Markdown / JSON report

## Phase 2 — Harness Runtime Strengthening

- Policy Adapter
- Execution Integrity Engine
- Evidence Report
- Behavior Pattern Engine v0.1

## Phase 3 — Security Demonstrations

- GitHub Governance Demo
- AWS Governance Demo
- MCP Gateway Demo
- API Security + AgentGuard Demo

## Phase 4 — Agent Memory & Reputation

- Agent Profile
- Agent History
- Risk Trend
- Reputation Score
- Behavior Pattern Summary

## Phase 5 — Ontology & Knowledge Graph

- Canonical Governance Model
- Domain Ontology Mapping
- API-to-Ontology Mapper
- Knowledge Graph Reasoning
- Relationship-based Risk Analysis

## Completion Criteria

The documentation and roadmap should make it clear:

- What AgentGuard is.
- Why AgentGuard is the Harness Layer.
- How Context Engineering relates to AgentGuard.
- Why the API Context Discovery Engine is necessary.
- Why Execution Integrity is a core differentiator.
- Why Behavior Pattern Taxonomy and Policy Pattern Taxonomy are necessary.
- Why Agent Reputation is necessary.
- How AgentGuard should evolve over time.
